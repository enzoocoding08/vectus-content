# Script and beats

## HOOK

Repeating one problem type feels efficient. It may be teaching you to follow a pattern, not choose a method.

## PROBLEM

Blocked practice makes the next step predictable: after five identical examples, you already know which method to use.

## EXPLANATION

Mix related problem types so each question forces a decision. Before solving, name the clue and choose the method.

## AHA

The extra difficulty is useful when it trains discrimination: not just how to execute a method, but when it applies.

## PRODUCT

Start small: learn each method, then mix two or three related types. Check accuracy and method choice; separate concepts that are still completely new.

## CTA

Save the recipe: Learn. Mix. Choose. Solve. Explain.

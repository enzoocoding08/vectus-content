# Script and beats

## HOOK

You got it wrong. Good. Now do this before your brain wastes the mistake.

## PROBLEM

Reading the solution can create instant familiarity without proving that you can produce the answer yourself.

## EXPLANATION

Name the cause: missing knowledge, wrong method, misread prompt, or careless execution. Repair only that cause, then close the solution.

## AHA

Redo the same problem from a blank page and explain why the corrected step works. A correct retry is stronger evidence than a familiar solution.

## PRODUCT

Retest with a similar question later. If the error returns, the gap is not repaired yet.

## CTA

Save the five-minute loop: Diagnose. Repair. Retrieve. Explain. Retest.
